## OmyDs 调研报告 技术栈：Python 3.11+ / uv / openai SDK（DeepSeek） / prompt_toolkit / Rich / bwrap / setpriv。 亮点：客户端持有权限、工具 purpose/impact 强制注解、整轮裁剪上下文、敏感文件黑名单、原子写、 控制字符净化（plain()）、拒绝后防绕过话术、记忆标记零额外请求。 缺陷：仅 Linux、无 CI/测试入库、记忆全文注入、字符预算非 token、无流式输出、生态极小（~1000 行）。
